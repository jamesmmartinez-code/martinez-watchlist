# Realm of Eldoria — Concept Art Reference

This folder is the **visual canon** for everyone building the game.

The Lorekeeper writes WHAT exists. The Concept Artist draws HOW it looks.
Architect, Character, Builder, and QA all reference these images before
they pick CC0 assets or commission Meshy generations.

## How to use

1. Reading lore? Open the matching folder here for visual context.
2. About to build a building, NPC, prop? Find the elevation/portrait
   here and match its silhouette + palette + mood.
3. Don't see a piece you need? Tell the Lorekeeper to write the doc;
   tell the Artist to draw it. Don't guess.
