# Eldoria Dirt-Path PBR Texture Set — Attribution

The three JPGs in this directory are procedurally generated by
`scripts/art/gen_dirt_path_texture.py` (committed alongside).
No third-party images, fonts, or trademarks are used.

## Files (1024×1024 JPG, tileable, painterly hand-painted feel)

| File              | Channel    | Purpose                                            |
|-------------------|-----------|----------------------------------------------------|
| `dirt_diff.jpg`   | albedo    | warm packed-earth color, sepia/sunset palette     |
| `dirt_norm.jpg`   | normal    | tangent-space normal derived from albedo height   |
| `dirt_rough.jpg`  | roughness | mostly rough (~0.78) with slight gloss in compacted hoof prints + pebble specks |

All three are tileable: edges wrap with low seam delta (verified at gen time).

## Why this exists

The `eldoria-godot/assets/textures/` set previously covered grass, wood,
stone, thatch, bark, rock, and snow — but no bare dirt / packed earth.
Briarwood Village and the Whisperwood approach roads need a tileable
walking-path texture so the Builder agent can lay paths between the
village square, the smithy, the herbalist, and the meadow gate. A future
Builder run will create a `MeshLibrary` tile or a flat `MeshInstance3D`
that uses these maps as its `StandardMaterial3D.albedo / normal /
roughness` slots.

## Style anchors (THEME.md)

- §1 painterly hand-painted aesthetic — no DSLR pebble grit, no photoreal
  micro-detail. Soft 0.6-radius Gaussian and brushy Perlin/FBM noise.
- §1 lived-in — sparse hoof prints (compaction depressions), occasional
  twig/leaf flecks, rare moss tufts in the cracks (~5% coverage).
- §3 palette — earth tones derived between burnt orange (`#FF8000`) and
  bronze (`#B0742A`); INK (`#0E0A0E`) for twig flecks; MOSS (`#4A7038`)
  for the rare green tufts; PARCHMENT (`#D9C99B`) lifted into highlights.
  No banned colors (no neon, no fluorescents, no pure white).

Mean diff RGB at gen time: (133, 101, 62) — warm and earthy, not grey.
