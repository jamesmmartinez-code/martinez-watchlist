# Eldoria Codex Glyph Icons — Attribution

The codex glyph PNGs in this directory are procedurally generated by
`scripts/art/gen_codex_glyphs.py` (committed alongside).
No third-party images, fonts, or trademarks are used.

## Files (128×128 RGBA PNG, transparent background, painterly heraldic glyphs)

| File                          | Codex entry                                   | Device                          | Palette anchor                      |
|-------------------------------|-----------------------------------------------|---------------------------------|-------------------------------------|
| `leaf-and-antler.png`         | `data/codex/stag_courts_courtesy.md`          | oak leaf + stag antler          | moss + bronze + parchment           |
| `horseshoe-and-cairn.png`     | `data/codex/steppe_riders_refusal.md`         | horseshoe arching over a cairn  | stone-blue + frost-silver + ink     |

Both glyphs are rendered onto a soft mottled parchment disc (semi-transparent)
with a worn bronze/stone ring and a brushy grain pass — matching the
hand-painted-feel mandate of THEME.md §1 and the §3 palette
(parchment #D9C99B, ink #0E0A0E, brass #B0742A, moss #4A7038, stone-blue
#7B8693, frost-silver #C8E0E5).

## Why these exist

Both codex .md files in `eldoria-godot/data/codex/` reference an `icon_glyph:`
value in their YAML frontmatter:

  - `stag_courts_courtesy.md`  → `icon_glyph: leaf-and-antler`
  - `steppe_riders_refusal.md` → `icon_glyph: horseshoe-and-cairn`

A future Builder/UI run that wires the codex panel will look up
`assets/icons/codex/<icon_glyph>.png` and blit it as the entry's tab badge.
Until this batch, those filenames did not exist on disk.
