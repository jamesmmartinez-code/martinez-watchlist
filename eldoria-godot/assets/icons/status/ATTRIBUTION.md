Each badge is a hand-painted-feel disc with a stylised symbol on a
slightly weathered painterly rim. Style targets THEME.md:

- §1 painterly, hand-painted concept-art aesthetic — soft brushstroke
  rim, Gaussian-softened edges, no crisp vector look.
- §3 palette compliance — every accent colour resolves to a hex in
  THEME.md §3 primary / secondary / magic bands. No neon, no
  fluorescent, no pure white background (transparent alpha used).
- §5 "Hand-painted look, not crisp vector" — final 0.30·SUPER Gaussian
  blur + LANCZOS downsample blends edges; soft circular alpha mask
  prevents any boxy disc edge.

## Why these exist

Eldoria's combat surfaces buff/debuff timing through small corner-of-
HUD badges. Until this run, no painterly status-effect set existed —
buffs and debuffs would have fallen back to legacy emoji glyphs the
rest of the game has retired in favor of 128×128 painterly PNG crests.
This 8-pack covers four warm-palette buffs (blessed, swift, shielded,
regen) and four cool/sickly-palette debuffs (burning, frozen, poisoned,
stunned) — wiring them to a buff bar becomes a pure UI task for the
next builder run.

## Pipeline

- Pillow / NumPy, no external image dependencies
- 256×256 supersampled canvas → 0.30·SUPER Gaussian softening →
  circular feathered alpha mask → LANCZOS downsample to 64×64
- Deterministic per-slug seeding (`sum(ord(c)) * 7`) so re-running the
  script yields byte-identical files
