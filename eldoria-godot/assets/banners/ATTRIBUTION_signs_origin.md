(Goldhaven, Ironhold, Silverleaf, Stormwatch, Embergrove, Frostpeak)

existing towns had banners only. These 3 signs let the WorldBuilder
agent place directional signposts at any path-fork or village-edge
without inventing new art.

## Style compliance — THEME.md

- §1 painterly hand-painted feel — wood-grain shading via per-stripe
  jitter, soft Gaussian blur (0.6·SUPER) before LANCZOS downsample to
  break crisp vector edges; faint moss/lichen speckle for "lived-in".
- §3 palette — wood mids `#684C32`, gold `#FFD86B`, ink `#0E0A0E`,
  moss `#4A7038`, crystal cyan `#65DFE5`. No neon, no fluorescent.
- §5 banners/signs — "Hand-painted look, not crisp vector. Slight
  irregularity, brushstroke edges. Wood-and-iron frames" — iron nails
  in 4 corners with darker rim, post + plank wood texture.
- §10 Hard Rule 9 — older / weathered / lived-in option chosen over
  clean modern signage.

512×256 RGBA PNG — same dimensions as the 6 existing `sign_to_*.png`
files, drop-in replacement for any signpost mesh material.
