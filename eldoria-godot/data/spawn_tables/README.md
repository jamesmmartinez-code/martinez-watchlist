# eldoria-godot/data/spawn_tables/

Authored by the **Bestiary Designer** agent. One `.tres` per region, with
the schema in `_spawn_table.gd`. Day/night entries swap on
`World.time_of_day` thresholds in the Builder agent's spawn loop.

Day vs. night is intentional ecology — skeletons crawl deeper at night,
crystal elementals dim and recede.
