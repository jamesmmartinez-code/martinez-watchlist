## Layout

For every material, four PBR maps + one Godot StandardMaterial3D resource:

```
eldoria-godot/assets/textures/<realm>/<name>/
  ├─ basecolor.png        # raw bake (lossless, kept as reference)
  ├─ normal.png           # tangent-space normal, lossless (precision-critical)
  ├─ roughness.png        # roughness map, lossless (precision-critical)
  ├─ ambientocclusion.png # raw bake (lossless, kept as reference)
  ├─ albedo.jpg           # JPEG q85 of basecolor — used by the .tres
  ├─ ao.jpg               # JPEG q85 of ambientocclusion — used by the .tres
  └─ <name>.tres          # StandardMaterial3D resource (load this in Godot)
```

The `.tres` references `albedo.jpg` + `normal.png` + `roughness.png` + `ao.jpg`
with `uv1_scale = Vector3(2, 2, 1)`. Tweak the UV scale per surface in
WorldBuilder.gd if you need denser tiling.

## Notes for the Environment Specialist agent

- WorldBuilder.gd's MAT_GRASS / MAT_WOOD / MAT_STONE / MAT_BARK / MAT_LEAF
  helpers do **not** auto-pick-up these `.tres`. Wire them in by name where
  appropriate — e.g. plateau_grass.tres for plateau ground, mossy_brick_wall
  for ruined walls in arch districts.
- All bakes are 256×256 right now (small Substance Sampler test outputs). Will
  upgrade to 1024×1024 in a future bake pass; the import pipeline already caps
  at 1024 via `-resize '1024x1024>'` so larger bakes will compress cleanly
  without breaking existing references.
- Existing CC0 packs (PolyHaven, AmbientCG) under
  `assets/textures/{grass,bark,dirt,rock,snow,stone,thatch,wood}/` remain in
  use; these Substance materials augment them.
